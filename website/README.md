# Produktseite (One-Page) für wunsch-fabrik.dk

`index.html` und den Ordner `img/` auf den Webspace laden, fertig. Die Seite braucht keine weiteren Dateien und lädt nichts von fremden Servern: keine Google-Schriften, kein Tracking, also auch kein Cookie-Banner nötig.

## Noch eintragen

Ganz unten in `index.html`, im Block `LINKS`:
- `buy`: die Kauf-Links von Lemon Squeezy je Programm
- `download`: die Links zu den Installern (z. B. GitHub-Release oder eigene Download-Seite)

Solange ein Link leer ist, springt der Knopf zu den Preisen.

Die Rechtstexte (Impressum, AGB, Datenschutz, Widerruf) verlinkt die Seite auf den Server unter `studio.wunsch-fabrik.dk/legal/…`. Die Adresse im Fuß (`id="addr"`) mit deiner Firmenanschrift ergänzen.

## Bilder

`img/*.jpg` sind Bildschirmfotos der Programme, `img/*.png` die Programmsymbole. Sie lassen sich jederzeit durch eigene Fotos ersetzen (gleicher Dateiname).
