1. Überblick: Was läuft wo?

Alle drei Programme laufen auf einem gemieteten Server im Internet. Deine Domain zeigt mit zwei Subdomains auf diesen Server. Deine normale Webseite (z. B. www.deinefirma.dk) bleibt, wo sie ist, und wird nicht verändert.

ProgrammAdresseWer benutzt es?
StickStudio (Sticksoftware)https://stick.deinefirma.dkDu als Admin. Später Kunden mit eigenem Konto (Testversion, dann Abo).
FräsStudio (CNC-Software)https://stick.deinefirma.dk/fraesstudio/Du. Später nur Kunden, die du in der Verwaltung freischaltest.
RechnungsStudiohttps://rechnung.deinefirma.dkNur du (mit Passwort). Kunden öffnen nur die Links zum Unterschreiben von Aufträgen.
Fachwörter kurz erklärt
  • Server: ein Computer in einem Rechenzentrum, der Tag und Nacht läuft. Du mietest ihn.
  • IP-Adresse: die Nummer des Servers im Internet, z. B. 1.2.3.4.
  • Subdomain: eine Unteradresse deiner Domain, z. B. stick.deinefirma.dk.
  • DNS / A-Eintrag: der Eintrag beim Domain-Anbieter, der sagt „diese Adresse wohnt auf jener IP“.
  • SSH: die Verbindung, mit der du vom eigenen Computer aus Befehle auf dem Server eingibst.
  • Terminal / PowerShell: das Fenster, in das du Befehle tippst.

2. Server mieten (Hetzner)

Ich empfehle Hetzner Cloud: günstig, Rechenzentren in Deutschland und Finnland (EU, wichtig für den Datenschutz), deutschsprachig. Andere Anbieter (netcup, IONOS, DigitalOcean …) gehen genauso. Du brauchst immer Ubuntu 24.04.

  1. Auf hetzner.com → „Cloud“ → Registrieren. Konto anlegen, E-Mail bestätigen, Zahlungsmittel hinterlegen. Hetzner prüft neue Konten manchmal kurz (Ausweis/Foto), das kann einige Stunden dauern.
  2. In der Cloud Console (console.hetzner.cloud) ein neues Projekt anlegen, Name z. B. Firma.
  3. Im Projekt „Server hinzufügen“ (bzw. „Ressource hinzufügen → Server“) und so einstellen:
    EinstellungWählen
    StandortFalkenstein oder Nürnberg (Deutschland) bzw. Helsinki
    ImageUbuntu 24.04
    Typ„Shared vCPU“, x86, das kleinste Modell mit 4 GB RAM (z. B. CX22 bzw. Nachfolger, ca. 4–5 € im Monat)
    NetzwerkÖffentliche IPv4 und IPv6 eingeschaltet lassen
    SSH-Keyleer lassen (dann bekommst du ein Passwort per E-Mail; einfacher für den Anfang)
    Backupseinschalten (kostet ca. 20 % mehr, sichert den ganzen Server täglich)
    Namez. B. firma-server
  4. „Kostenpflichtig erstellen“. Nach etwa einer Minute läuft der Server.
  5. Notiere dir die IPv4-Adresse des Servers (steht in der Übersicht, z. B. 1.2.3.4).
  6. Hetzner schickt dir eine E-Mail mit dem root-Passwort. Gut aufheben.
Wichtig: Der Benutzer root darf auf dem Server alles. Gib das Passwort niemandem und speichere es in einem Passwort-Manager.

3. Subdomains bei deinem Domain-Anbieter anlegen

Das machst du dort, wo deine Domain registriert ist (z. B. Simply.com, one.com, IONOS, Strato, GoDaddy …). Der Menüpunkt heißt meist „DNS“, „DNS-Einstellungen“, „DNS-Records“ oder „Domain verwalten“.

  1. Beim Domain-Anbieter einloggen und die DNS-Einstellungen deiner Domain öffnen.
  2. Neuen Eintrag anlegen („Record hinzufügen“):
    TypName / HostWert / Ziel / Zeigt aufTTL
    Astick1.2.3.4 (IP deines Servers)Standard bzw. 1 Stunde
    Arechnung1.2.3.4 (dieselbe IP)Standard bzw. 1 Stunde
    Manche Anbieter wollen beim Namen die ganze Adresse (stick.deinefirma.dk), andere nur stick. Das steht meist als Beispiel daneben.
  3. Speichern. Die vorhandenen Einträge (für deine Webseite und E-Mail) nicht ändern oder löschen.
  4. Warten, meist 5–30 Minuten, selten bis zu einigen Stunden.
  5. Prüfen: Auf dem eigenen Computer ein Terminal öffnen (siehe Teil 4) und eingeben: 
    ping stick.deinefirma.dk
    Erscheint dort deine Server-IP (1.2.3.4), ist alles richtig. Mit Strg + C beenden. Das Gleiche für rechnung.deinefirma.dk.
Die Namen stick und rechnung sind Vorschläge. Du kannst auch z. B. studio oder faktura nehmen. Dann überall in der Anleitung entsprechend ersetzen.

4. Das erste Mal mit dem Server verbinden

Terminal öffnen

Windows 10/11Mac
Startmenü → „PowerShell“ eintippen → öffnen. Die Befehle ssh und scp sind schon eingebaut. Programme → Dienstprogramme → „Terminal“.

Verbinden

  1. Eingeben: 
    ssh root@1.2.3.4
  2. Beim ersten Mal fragt er: „Are you sure you want to continue connecting?“ → yes eintippen, Enter.
  3. Passwort aus der Hetzner-E-Mail eingeben. Beim Tippen erscheinen keine Zeichen, das ist normal. Enter.
  4. Eventuell musst du das Passwort sofort ändern: altes Passwort eingeben, dann zweimal ein neues, langes Passwort.
  5. Du siehst jetzt etwas wie root@firma-server:~#. Ab hier landet alles, was du tippst, auf dem Server.

Server auf den neuesten Stand bringen

apt-get update && apt-get upgrade -y && apt-get install -y unzip unattended-upgrades

Das dauert ein paar Minuten. Erscheint ein blaues Fenster mit einer Frage, einfach Enter drücken (Vorauswahl übernehmen). unattended-upgrades spielt ab jetzt Sicherheitsupdates automatisch ein.

Danach einmal neu starten und nach einer Minute wieder verbinden:

reboot
ssh root@1.2.3.4

Die Verbindung beendest du später jederzeit mit exit.

5. Das Programmpaket auf den Server kopieren

Du hast von mir die Datei Komplettpaket.zip bekommen. Sie enthält alle drei Programme. Speichere sie in deinem Downloads-Ordner.

  1. Ein zweites Terminal-Fenster auf deinem Computer öffnen (das erste bleibt mit dem Server verbunden).
  2. Im zweiten Fenster die Datei hochladen:
    Windows (PowerShell)
    scp "$HOME\Downloads\Komplettpaket.zip" root@1.2.3.4:/root/
    Mac (Terminal)
    scp ~/Downloads/Komplettpaket.zip root@1.2.3.4:/root/
    Server-Passwort eingeben. Es erscheint ein Fortschrittsbalken bis 100 %.
  3. Zurück im ersten Fenster (auf dem Server) entpacken: 
    cd /root
unzip -o Komplettpaket.zip
cd Komplettpaket
Lieber mit der Maus? Unter Windows geht das Hochladen auch mit dem kostenlosen Programm WinSCP (Mac: Cyberduck): Protokoll SFTP, Server 1.2.3.4, Benutzer root, dein Passwort. Dann die ZIP-Datei nach /root ziehen.

6. StickStudio und FräsStudio einrichten

StickStudio und FräsStudio laufen zusammen unter stick.deinefirma.dk. Das Einrichtungsskript erledigt alles: Node.js, Programm, HTTPS-Zertifikat, automatischer Start, Firewall und tägliche Sicherung.

  1. Im Server-Fenster, im Ordner /root/Komplettpaket: 
    bash deploy/install.sh
  2. Das Skript stellt nacheinander diese Fragen:
    FrageDeine Antwort
    Auswahl [1/2] (Eigener Webserver oder neben vorhandenem)1
    Adresse (Subdomain …)stick.deinefirma.dk
    Deine E-Mail (Admin-Login)du@deinefirma.dk
    Dein Passwort (mindestens 10 Zeichen)ein neues, langes Passwort (unsichtbar beim Tippen)
    Firewall einschalten? [j/N]j
  3. Jetzt arbeitet das Skript 3–10 Minuten (Pakete laden, Programm bauen, KI-Modell für FräsStudio laden). Am Ende steht: 
    Fertig! Öffne: https://stick.deinefirma.dk
Verwaltung:   https://stick.deinefirma.dk/admin
FräsStudio:   https://stick.deinefirma.dk/fraesstudio/
  4. Im Browser https://stick.deinefirma.dk öffnen und mit E-Mail und Passwort anmelden. Das Schloss in der Adresszeile zeigt, dass HTTPS funktioniert.
  5. Passwort-Sicherheit: Unter „Mein Konto“ das Passwort einmal ändern. Danach im Server-Fenster die Zeile mit dem Startpasswort löschen: 
    nano /etc/stickstudio.env
    Mit den Pfeiltasten zur Zeile ADMIN_PASSWORD=…, mit Strg + K die Zeile löschen, mit Strg + O und Enter speichern, mit Strg + X schließen. Dann: 
    systemctl restart stickstudio
  6. FräsStudio öffnen: https://stick.deinefirma.dk/fraesstudio/. Als Admin hast du immer Zugang.
Fräse steuern: Die Fräse wird über USB an deinem Computer gesteuert. Das geht nur in Google Chrome oder Microsoft Edge. Die „WLAN-Brücke“ zur Fräse funktioniert nur, wenn der Server bei dir zu Hause im selben Netz steht (Homeserver), nicht bei einem gemieteten Server.

7. RechnungsStudio einrichten

  1. Im Server-Fenster, weiterhin im Ordner /root/Komplettpaket: 
    bash rechnung/deploy/install.sh
  2. Die Fragen:
    FrageDeine Antwort
    Name dieser Kopie (Enter = rechnung …)einfach Enter
    Adresse (Subdomain …)rechnung.deinefirma.dk
    Passwort für RechnungsStudio (mindestens 10 Zeichen)ein eigenes, langes Passwort (nicht dasselbe wie für StickStudio)
  3. Nach 1–3 Minuten steht da: Fertig! Öffne: https://rechnung.deinefirma.dk
  4. Im Browser öffnen. Es erscheint ein Anmeldefenster: Benutzername beliebig (z. B. dein Name), Passwort wie eben eingegeben. Der Browser kann es sich merken.
Gut zu wissen: Die Adresse für Kunden-Links (Aufträge zum Unterschreiben) ist automatisch eingetragen. Die Unterschriftsseite für Kunden braucht kein Passwort, alles andere ist geschützt.

8. Die Programme zum ersten Mal benutzen

RechnungsStudio

  1. Einstellungen: Firmenname, CVR-Nr., Adresse, E-Mail, Logo, Bankverbindung (Lunar: Reg.-Nr., Konto, IBAN) und Momsperiode eintragen → Speichern.
  2. Belegerkennung (optional): unter Einstellungen den API-Schlüssel von platform.claude.com eintragen.
  3. Kunden anlegen (Sprache Deutsch/Dänisch/Englisch wählen), Produkte mit Bild anlegen.
  4. Handy: https://rechnung.deinefirma.dk/#/belege im Handy-Browser öffnen, anmelden, dann „Zum Startbildschirm hinzufügen“ (iPhone: Teilen-Knopf; Android: Menü ⋮). Jetzt hast du die Belege-Kamera wie eine App, auch unterwegs.
  5. Daten vom Computer übernehmen: Hast du RechnungsStudio vorher auf deinem Computer benutzt, dort unter Einstellungen → „Sicherung herunterladen“ und auf dem Server unter Einstellungen → „Sicherung einspielen“. Belegfotos werden dabei nicht mitgenommen (siehe Teil 12).

StickStudio

  1. Unter /admin → Einstellungen & Firmendaten: Firmendaten eintragen. Daraus werden Impressum, AGB und Datenschutz gefüllt.
  2. Designs anlegen, Stickdateien (DST usw.) exportieren wie gewohnt.

FräsStudio

  1. https://stick.deinefirma.dk/fraesstudio/ in Chrome oder Edge öffnen.
  2. Fräse per USB anschließen → Schritt 4 „Fräsen“ → Verbinden. Alles Weitere steht in der Hilfe von FräsStudio.

9. E-Mail-Versand einrichten (für StickStudio)

StickStudio schickt E-Mails (Registrierung, „Passwort vergessen“, Kündigungsbestätigung). Ohne E-Mail-Einstellungen landen diese nur im Protokoll. Für Kunden ist das Pflicht.

  1. Bei deinem E-Mail-Anbieter ein Postfach anlegen, z. B. noreply@deinefirma.dk, und die SMTP-Daten heraussuchen (Server, Port, Benutzer, Passwort). Die stehen in der Hilfe deines Anbieters unter „SMTP“ oder „E-Mail-Programm einrichten“.
  2. Im Server-Fenster: 
    nano /etc/stickstudio.env
    Bei diesen Zeilen das # am Anfang löschen und deine Daten eintragen: 
    SMTP_HOST=smtp.dein-anbieter.dk
SMTP_PORT=465
SMTP_USER=noreply@deinefirma.dk
SMTP_PASS=dein-postfach-passwort
MAIL_FROM=noreply@deinefirma.dk
    Speichern (Strg + O, Enter), schließen (Strg + X).
  3. Neu starten: systemctl restart stickstudio
  4. Testen: auf der Anmeldeseite „Passwort vergessen“ mit deiner E-Mail ausprobieren.

10. Später für Kunden

10.1 StickStudio an Kunden verkaufen

  1. Registrierung: Kunden registrieren sich selbst auf https://stick.deinefirma.dk und bekommen sofort eine Testversion (Standard 14 Tage, in der Verwaltung einstellbar). Danach können sie nur noch ansehen, bis sie ein Abo haben.
  2. Bezahlung mit Lemon Squeezy (kümmert sich um Rechnungen und Moms/MwSt. in der EU):
    1. Konto bei lemonsqueezy.com anlegen, Shop einrichten, ein Abo-Produkt (Subscription, monatlich oder jährlich) anlegen.
    2. Den Checkout-Link des Produkts in der StickStudio-Verwaltung als Abo-Link eintragen.
    3. Bei Lemon Squeezy unter Settings → Webhooks einen Webhook anlegen: URL https://stick.deinefirma.dk/api/webhook/lemonsqueezy, ein selbst gewähltes Signing secret, alle Abo-Ereignisse (subscription_…) anhaken.
    4. Unter Settings → API einen API-Schlüssel erzeugen.
    5. Beides in /etc/stickstudio.env eintragen (Raute entfernen) und neu starten: 
      LEMONSQUEEZY_SECRET=dein-signing-secret
LEMONSQUEEZY_API_KEY=dein-api-schluessel
      systemctl restart stickstudio
    Ab dann folgt die Lizenz automatisch dem Abo: aktiv, gekündigt oder beendet.
  3. Rechtstexte: Impressum, AGB, Widerruf und Datenschutz sind als Entwürfe dabei und werden aus deinen Firmendaten gefüllt. Sie sind nach deutschem Recht geschrieben. Als dänische Firma solltest du sie von einem Anwalt bzw. deinem revisor an dänisches Recht anpassen lassen (z. B. Forbrugeraftaleloven, Datatilsynet als Aufsichtsbehörde), bevor du verkaufst.
  4. Nur für dich nutzen? Dann neue Registrierungen sperren: in /etc/stickstudio.env bei #REGISTRATION=closed die Raute entfernen, systemctl restart stickstudio.

10.2 FräsStudio für Kunden freischalten

  1. Der Kunde registriert sich ganz normal in StickStudio (oder du legst ihm ein Konto an).
  2. In der Verwaltung → Benutzer → Bearbeiten das Häkchen „Zugang zu FräsStudio“ setzen.
  3. Der Kunde öffnet https://stick.deinefirma.dk/fraesstudio/. Ohne Häkchen sieht er „nicht freigeschaltet“.
Wer FräsStudio-Zugang hat, kann eine angeschlossene Fräse steuern. Nur vertrauenswürdigen Kunden freischalten.

10.3 RechnungsStudio

  • Deine Kunden brauchen nichts zu tun. Sie bekommen von dir Rechnungen (PDF) und Links zum Unterschreiben von Aufträgen.
  • RechnungsStudio an andere Firmen vermieten: Jede Firma bekommt eine eigene, getrennte Kopie mit eigener Adresse, eigenen Daten und eigenem Passwort:
    1. Beim Domain-Anbieter einen weiteren A-Eintrag anlegen, z. B. mueller → 1.2.3.4.
    2. Auf dem Server im Ordner /root/Komplettpaket: bash rechnung/deploy/install.sh
    3. Name der Kopie: z. B. rechnung-mueller; Adresse: mueller.deinefirma.dk; ein Passwort für den Kunden.
    Rechtlich bist du dann Datenverarbeiter für diese Firma: Du brauchst einen Vertrag über die Datenverarbeitung (Databehandleraftale) und eigene AGB. Außerdem musst du für Sicherungen und Updates sorgen.

11. Updates einspielen

Wenn du von mir ein neues Komplettpaket.zip bekommst:

  1. Hochladen wie in Teil 5 (zweites Fenster, scp …).
  2. Im Server-Fenster: 
    cd /root
rm -rf Komplettpaket
unzip -o Komplettpaket.zip
cd Komplettpaket
bash deploy/install.sh
bash rechnung/deploy/install.sh
  3. Die Skripte erkennen die bisherige Einrichtung und fragen nur wenig nach (bei RechnungsStudio nur den Namen der Kopie: Enter). Alle Daten bleiben erhalten, sie liegen getrennt vom Programm.
  4. Für weitere RechnungsStudio-Kopien (Kunden): bash rechnung/deploy/install.sh noch einmal und den jeweiligen Namen eingeben, z. B. rechnung-mueller.

13. Wenn etwas nicht klappt

ProblemLösung
Die Adresse öffnet sich nicht / „Seite nicht erreichbar“DNS-Eintrag prüfen: ping stick.deinefirma.dk muss die Server-IP zeigen. Sonst Eintrag beim Domain-Anbieter kontrollieren und warten.
Browser warnt „nicht sicher“ / ZertifikatsfehlerDas Zertifikat wird erst geholt, wenn der DNS-Eintrag stimmt. DNS prüfen, dann systemctl restart caddy. Meldungen: journalctl -u caddy -n 50 --no-pager
StickStudio antwortet nichtsystemctl status stickstudio und journalctl -u stickstudio -n 50 --no-pager
RechnungsStudio antwortet nichtsystemctl status rs-rechnung und journalctl -u rs-rechnung -n 50 --no-pager
RechnungsStudio-Passwort vergessennano /etc/rs-rechnung.env → Zeile PASSWORD= ändern → systemctl restart rs-rechnung
StickStudio-Admin-Passwort vergessenMit E-Mail-Versand: „Passwort vergessen“ auf der Anmeldeseite. Ohne: im Server-Fenster 
cd /opt/stickstudio
sudo -u stickstudio DATA_DIR=/var/lib/stickstudio node --no-warnings server/reset-password.js du@deinefirma.dk 'neues-langes-passwort'
Das geht auch für Kundenkonten.
„Permission denied“ beim sshPasswort falsch (Groß/Klein beachten) oder Benutzer nicht root. In der Hetzner Console kann man das root-Passwort zurücksetzen.
Server-Fenster hängt / alles wegFenster schließen, neu mit ssh root@1.2.3.4 verbinden. Die Programme laufen unabhängig davon weiter.
Wenn du nicht weiterkommst: die letzten Zeilen der Meldungen (Befehl journalctl …) kopieren und mir schicken.

14. Ohne Server benutzen (nur auf deinem Computer)

ProgrammSo startest du es

15. Checkliste

  • Hetzner-Konto angelegt, Server mit Ubuntu 24.04 erstellt, Backups an
  • IP-Adresse und root-Passwort notiert
  • A-Einträge stick und rechnung angelegt, ping zeigt die Server-IP
  • Mit ssh verbunden, Updates eingespielt
  • Komplettpaket.zip hochgeladen und entpackt
  • bash deploy/install.sh fertig, StickStudio-Login klappt, Admin-Passwort geändert
  • FräsStudio unter /fraesstudio/ öffnet sich
  • bash rechnung/deploy/install.sh fertig, RechnungsStudio-Login klappt
  • RechnungsStudio: Firmendaten, Bank, Momsperiode eingetragen; Handy-Verknüpfung angelegt
  • E-Mail-Versand für StickStudio eingerichtet
  • Erste Sicherung auf den eigenen Computer geholt
  • (Später) Lemon Squeezy, Rechtstexte nach dänischem Recht, Kunden freischalten
