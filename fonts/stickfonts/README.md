# Eingebaute Stickschriften

Diese fertig digitalisierten Stickschriften stammen aus einer frei lizenzierten Sammlung.

- Übernommen wurden nur die **Schriftdaten** (Satinsäulen, Laufstiche, Füllungen, Abstände, Unterschneidungen),
  umgewandelt in das StickStudio-Format (`js/stickfonts/*.js`). Programmcode wurde **nicht** übernommen.
- Jede Schrift behält ihre eigene Lizenz, siehe `LICENSE` im jeweiligen Unterordner:
  - **OFL-1.1** (SIL Open Font License): frei nutzbar, auch gewerblich. Veränderte Fassungen dürfen nicht unter einem reservierten Namen weitergegeben werden. Die reservierten Namen gehören hier zu den Ursprungsschriften (z. B. „Lobster“, „Merienda“). Verwendet werden nur die eigenen Namen der bearbeiteten Fassungen (z. B. „Stebor AGS“, „Marifenda“).
  - **CC-BY-SA**: frei nutzbar, auch gewerblich, mit Namensnennung. Veränderte Schriften müssen unter derselben Lizenz weitergegeben werden.
  - **gemeinfrei**: ohne Einschränkungen.
- Gestickte Ergebnisse (DST-Dateien, bestickte Produkte) sind keine Weitergabe der Schrift und dürfen frei verkauft werden.
