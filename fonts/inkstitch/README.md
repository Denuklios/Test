# Stickschriften aus der Ink/Stitch-Sammlung

Diese fertig digitalisierten Stickschriften stammen aus der Schriftsammlung von
[Ink/Stitch](https://inkstitch.org) ([github.com/inkstitch/embroidery-fonts](https://github.com/inkstitch/embroidery-fonts)).
Ink/Stitch ist eine kostenlose Stick-Erweiterung für das Zeichenprogramm Inkscape.

- Übernommen wurden nur die **Schriftdaten** (Satinsäulen, Laufstiche, Füllungen, Abstände, Unterschneidungen).
  Sie wurden mit `tools/inkstitch_fonts.py` in das StickStudio-Format umgewandelt (`js/inkfonts/*.js`).
- Programmcode von Ink/Stitch (GPL-3.0) wurde **nicht** übernommen.
- Jede Schrift behält ihre eigene Lizenz, siehe `LICENSE` im jeweiligen Unterordner:
  - **OFL-1.1** (SIL Open Font License): frei nutzbar, auch gewerblich. Veränderte Fassungen dürfen nicht unter einem reservierten Namen weitergegeben werden. Die reservierten Namen gehören hier zu den Ursprungsschriften (z. B. „Lobster“, „Merienda“). Verwendet werden nur die eigenen Namen der Ink/Stitch-Fassungen (z. B. „Stebor AGS“, „Marifenda“).
  - **CC-BY-SA**: frei nutzbar, auch gewerblich, mit Namensnennung. Veränderte Schriften müssen unter derselben Lizenz weitergegeben werden.
  - **gemeinfrei**: ohne Einschränkungen.
- Gestickte Ergebnisse (DST-Dateien, bestickte Produkte) sind keine Weitergabe der Schrift und dürfen frei verkauft werden.
