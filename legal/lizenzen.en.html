1. Embroidery fonts (ready-digitized)

The conversion has produced modified versions (adaptations) of the font data. These modified font data are distributed under the same licence as the respective original version of the font: fonts under the SIL Open Font License 1.1 remain under OFL-1.1, fonts under a Creative Commons Attribution-ShareAlike licence (CC BY-SA) remain under CC BY-SA in the version stated, and public domain fonts remain in the public domain. The font data are not sold by themselves.

4. Thread colour tables

The thread colour tables (colour number, colour name and approximate RGB value) were taken from freely available colour palette data of an open-source project. Only these data were taken over, no program code. Tables are included for: Madeira Polyneon, Madeira Rayon (Classic), Madeira Burmilana, Isacord Polyester, Gunold Polyester, Robison-Anton Polyester, Robison-Anton Rayon, Sulky Rayon, Sulky Polyester, Mettler Poly Sheen, Marathon Polyester, Brother Embroidery, Coats Alcazar, Gütermann Creativ Dekor.
